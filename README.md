# strtoolz

Extra string search and manipulation functions for Python.

- `find_all()`
- `find_iter()`

## Usage

```python
>>> import strtoolz
>>> strtoolz.find_all("The rain in Spain falls mainly on the plain", 'ain')
[5, 14, 25, 40]
```
